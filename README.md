## GitHub에 올리는 방법
1. 이 ZIP의 **압축을 풉니다.**
2. 압축 해제한 `Binghayu-BBangD_GitHub_Pages` 폴더 **안으로 들어갑니다.**
3. 다음 항목을 모두 선택합니다: `index.html`, `game.js`, `style.css`, `README.md`, `assets` 폴더.
4. https://github.com/meltingchoco127-jpg/Binghayu-BBangD 저장소를 엽니다.
5. `Code` 탭의 파일 목록 위쪽 **Add file → Upload files**를 선택합니다.
6. 위에서 선택한 파일들과 **assets 폴더를 함께** 드래그해서 업로드합니다.
   `index.html`이 `Binghayu-BBangD_GitHub_Pages`라는 중간 폴더 안으로 들어가면 안 됩니다.
7. 같은 파일명이 있을 때는 변경 내용 확인 후 **Commit changes**를 누릅니다.
8. `Settings → Pages → Build and deployment`에서 `Deploy from a branch`, `main`, `/(root)`를 설정하고 `Save`를 누릅니다.
9. 배포가 완료되면 https://meltingchoco127-jpg.github.io/Binghayu-BBangD/ 로 접속합니다.
